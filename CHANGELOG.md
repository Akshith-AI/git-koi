## [0.1.0] - 2026-11-25

### Added

- Public LeetCode collection with difficulty counts, overlapping topic
  statistics, calendar availability, and recent accepted submissions.
- Original male Halfmoon betta anatomy and koi marbling, including gold and
  orange.
- Upright side-to-side swimming with independently moving fins, a shared pond,
  GIF export, and a self-hosted website widget with hover, focus, and tap
  flaring.
- Pause controls, reduced motion, fixed-camera fin details, and attribution.
- LTKoi GitHub Action with betta, pond, and GitHub-only koi modes, configurable
  usernames, cached snapshot inputs, and verified release downloads.
- Daily refresh workflow, copyable profile setup, browser tests, and portable
  release binaries for Linux, macOS, and Windows.

### Changed

- Renamed the fork's package and command to `ltkoi`, version 0.1.0.
- Release assets and Action now belong to Akshith-AI/git-koi. Publishing the
  original author's crates.io package is disabled.
