This fork adds a public LeetCode profile collector, snapshot validation,
original male Halfmoon betta geometry and koi marbling, animation, a shared pond
compositor, and interactive website embeds with hover/focus/touch flaring. The
new GIF path uses deterministic palette reduction, while the original
exact-color encoder is retained. Implementation status is tracked in
docs/roadmap.md.

The reference photograph informs the intended fish anatomy and color style; it
is not included as a project asset. Betta graphics are drawn by the renderer.
